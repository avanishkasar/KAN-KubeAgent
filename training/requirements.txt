# Plain `pip install -r training/requirements.txt` installs the CPU-only
# torch wheel by default, even on a machine with an NVIDIA GPU - PyPI's
# default index doesn't ship CUDA builds. Training still works either way
# (falls back to CPU, see fashion_mnist_cnn.py), but if you have an NVIDIA
# GPU and want the Live dashboard to actually exercise it, install from
# PyTorch's CUDA index INSTEAD of this file:
#
#   pip install torch --index-url https://download.pytorch.org/whl/cu121
#   pip install torchvision
#
# (cu121 = CUDA 12.1; check https://pytorch.org/get-started/locally/ for the
# build matching your installed CUDA driver version - `nvidia-smi` shows it
# in the top-right "CUDA Version" field). Then verify with:
#
#   python -c "import torch; print(torch.cuda.is_available())"
#
# fashion_mnist_cnn.py logs a warning to the live event log if it detects a
# GPU via nvidia-smi but torch itself has no CUDA support, so you don't have
# to guess why the GPU tile stays idle during a run.
